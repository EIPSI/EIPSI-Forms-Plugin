# Your first study

[Documentation index](../README.md)

Use a disposable study and test participants for this walkthrough.

1. Open **EIPSI Forms → Configuration**. Choose English or Spanish. Review storage and privacy settings. For a longitudinal study, configure SMTP and check the scheduler before expecting automatic emails.
2. Open **Assessment Editor** and create an assessment. Add a few questions, give them meaningful variable names, and use a page break if you want multiple pages.
3. Check required responses, validation messages, navigation, and the final screen. Use the preview, save the draft, and publish a version.
4. Open **Study Engine** and create a study. Choose **Cross-sectional** for an immediate assessment or **Longitudinal** for scheduled opportunities and email-based participation.
5. Select the published assessment and its version. For longitudinal studies, add a longitudinal block and schedule an interaction. Keep the first example simple; add randomization and conditions after checking the basic route.
6. For longitudinal studies, edit **Initial screen**, the authentication settings, the withdrawal screens, and the selected email templates.
7. Open **Tests**. Resolve validation errors and try the simulated experience. A simulation does not create real participant records or deliver emails.
8. Publish the study version, activate the study, and copy its public link. Publication and activation are separate actions.
9. Open that link as a participant and complete the assessment. If emails are required, follow the actual email link as well.
10. Open **Manage** for the study. Find the participation, inspect its assessment version and response, and prepare a sample export.

See [assessments](assessments.md), [studies](studies.md), and [data](data-and-api.md) for the individual controls.
